# Movie Explorer

Веб-приложение для поиска фильмов с использованием TMDB API. Позволяет искать фильмы, фильтровать результаты, просматривать детальную информацию и сохранять избранное.

**Live Demo:** https://movie-search-app-beta-coral.vercel.app/

## Основной функционал

- **Поиск фильмов** — по названию с запуском через Enter или кнопку
- **Фильтрация** — по жанру, году выхода и минимальному рейтингу
- **Сортировка** — по популярности, рейтингу или дате релиза
- **Страница деталей** — постер, описание, жанры, длительность, рейтинг
- **Избранное** — сохранение в LocalStorage (данные не теряются после перезагрузки)
- **Адаптивный дизайн** — корректно отображается на десктопе и мобильных устройствах
- **Обработка состояний** — индикаторы загрузки, обработка ошибок, пустые состояния

## Технологии

- **React 18** — библиотека для построения UI
- **TypeScript** — типизация для надёжности кода
- **Vite** — быстрая сборка и dev-сервер
- **React Router v6** — маршрутизация между страницами
- **CSS Modules** — изолированные стили компонентов
- **TMDB API** — источник данных о фильмах

## Локальный запуск

### Требования

- Node.js 16+
- npm или yarn

### Установка

1. Клонируйте репозиторий

```bash
git clone https://github.com/your-username/movie-explorer.git
cd movie-explorer
```

2. Получите API токен на TMDB:

https://www.themoviedb.org/settings/api

3. Создайте файл `.env` в корне проекта:

```env
VITE_TMDB_TOKEN=your_token_here
```

4. Установите зависимости и запустите проект:

```bash
npm install
npm run dev
```

Приложение откроется на:

```txt
http://localhost:5173
```

## Структура проекта

```txt
src/
├── api/                    # Слой работы с TMDB API
│   └── tmdb.ts             # Все fetch-запросы в одном месте
├── components/             # Переиспользуемые компоненты
│   ├── SearchBar/
│   ├── MovieCard/
│   ├── Loader/
│   └── ...
├── hooks/                  # Кастомные хуки
│   └── useFavorites.ts     # Управление избранным (LocalStorage + state)
├── pages/                  # Страницы приложения
│   ├── Home.tsx
│   ├── Movies.tsx
│   ├── MovieDetails.tsx
│   ├── Favorites.tsx
│   └── NotFound.tsx
├── types/                  # TypeScript типы
│   └── movie.ts
└── utils/                  # Вспомогательные функции
    └── toMovie.ts
```

## Ключевые решения

- **Кастомный хук `useFavorites`** — инкапсулирует логику работы с LocalStorage и синхронизирует состояние избранного между компонентами
- **Централизованный API-слой** — все запросы к TMDB вынесены в отдельный модуль для удобства поддержки
- **TypeScript типизация** — типы для всех сущностей (`Movie`, `Genre`, `APIResponse`) для безопасности на этапе разработки
- **Обработка граничных случаев** — состояния загрузки, ошибок API, пустые результаты поиска
